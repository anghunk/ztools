# ztools

这是一个简单的工具库，纯前端实现，无后台代码已开源，没有手机端适配的计划。

![](https://img.shields.io/github/stars/anghunk/ztools?logo=github&style=flat-square&label=Stars)
![](https://img.shields.io/github/license/anghunk/ztools?style=flat-square&label=License)

[在线演示](https://ztools.zishu.me)

## 本地开发

```shell
git clone https://github.com/anghunk/ztools.git
cd ztools

npm install
npm run dev
```
